# Solid Vibes is a setup for builders

**Date:** 2026-10-24
**Who decided:** mine

## Context

The first audience description shut developers out, which reads as a wall and is not true: the same method serves everyone.

## Decision

"Solid Vibes is a setup for builders. Anyone can be a builder." One product, no beginner and expert tracks. People who have never written code gain the most; developers use it as it is or swap the stack profile. Brand line: "Everybody's building now. They should be building better." Tagline: "vibe coding that holds up". Texts never say "not for developers".

## Why

Plain language is how the method works for everyone, so it stays: outcome questions, a visual for every decision, no assumed knowledge of git, a terminal or any framework.

## Alternatives

Separate beginner and expert modes (two products to keep true).

## What it means

README and skill texts use plain words and never claim users, ratings or results. Solid Vibes is the method; an extension such as Flutter and Supabase is packaged stack decisions on top of it. It is not one product split by price.
